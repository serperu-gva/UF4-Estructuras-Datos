::: info Síntesis de la unidad
Esta unidad se centra en el estudio de las estructuras de datos básicas, como los vectores y las matrices. Aprenderéis a declararlas, acceder a ellas, modificarlas y aplicar operaciones frecuentes como la búsqueda y la ordenación. Estas herramientas son esenciales para gestionar colecciones de información de manera eficiente dentro de vuestros programas.
:::

## 📋 Objetivos del Curso {.animate-title}

::: tip Objetivos cubiertos y relación con RA

Este tema aborda los conceptos prácticos y sintácticos de un lenguaje de programación específico, que son la base para escribir código funcional.

- Objetivo 5.1: Declarar y manipular **vectores** (arrays unidimensionales) para almacenar y acceder a datos de forma secuencial.
- Objetivo 5.2: Utilizar **matrices** (arrays multidimensionales) para organizar datos en dos o más dimensiones.
- Objetivo 5.3: Aplicar métodos de bibliotecas de clases para realizar operaciones comunes como la búsqueda y la ordenación.
- Objetivo 5.4: Emplear el bucle **`foreach`** para recorrer de manera eficiente los elementos de vectores y matrices.
- Objetivo 5.5: Utilizar las capacidades de entrada/salida del lenguaje para interactuar con el usuario y procesar datos.
