# 1. Introducción

Un **vector** o **array** es una colección de **valores de un mismo tipo** dentro de una misma variable, de manera que se puede acceder a cada valor de forma independiente.

Los vectores solucionan problemas relacionados con la gestión de muchas variables que hacen referencia a datos similares.
Por ejemplo, si necesitáramos almacenar las notas de una clase con 18 alumnos, habría que declarar 18 variables, con la gran dificultad de gestión que eso supone.

Solo calcular la nota media exigiría una línea de código muy extensa. Almacenar las notas supondría al menos 18 líneas de código.

En lugar de crear 18 variables, sería mucho mejor declarar un vector de tamaño 18 (es como si tuviéramos una sola variable capaz de almacenar varios valores).

Gracias a los vectores se puede crear un conjunto de variables con el mismo nombre. La diferencia es que un número (el índice del vector) permite distinguir cada valor.
